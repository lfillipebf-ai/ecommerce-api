# Ecommerce API

API REST de e-commerce para portfólio, desenvolvida com Java e Spring Boot.

## Tecnologias
Java 17, Spring Boot, Spring Data JPA, Spring Security, PostgreSQL, Maven, Docker, REST API e Git/GitHub.

## Funcionalidades
- Produtos e categorias
- Clientes
- Pedidos e itens de pedido
- Controle de estoque
- Validação de dados
- Autenticação preparada para JWT
- Persistência PostgreSQL
- Docker Compose

## Execução
1. Tenha Docker instalado.
2. Execute: docker compose up --build
3. API: http://localhost:8080

## Endpoints
GET/POST /api/products
GET/POST /api/categories
GET/POST /api/customers
GET/POST /api/orders

Projeto educacional/portfólio criado para praticar backend, APIs REST, banco de dados e orientação a objetos.
